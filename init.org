* 包管理器 (Elpaca)

Elpaca 是一个现代化的 Emacs 包管理器，支持异步安装、懒加载和从 Git 仓库
直接拉取包。以下为官方推荐的 bootstrap 代码，首次启动时会自动克隆并编译
Elpaca 本身。

=elpaca-core-date= 必须在加载 Elpaca 之前设定。当前 Elpaca 内置的发行日
期表只到 30.2，在 Emacs 31 上不设这个值会报
=Unable to determine elpaca-core-date=。31.1 的官方发布日是 2026-08-24。

#+begin_src emacs-lisp
(setq elpaca-core-date '(20260824))

(defvar elpaca-installer-version 0.12)
(defvar elpaca-directory (expand-file-name "elpaca/" user-emacs-directory))
(defvar elpaca-builds-directory (expand-file-name "builds/" elpaca-directory))
(defvar elpaca-sources-directory (expand-file-name "sources/" elpaca-directory))
(defvar elpaca-order '(elpaca :repo "https://github.com/progfolio/elpaca.git"
                              :ref nil :depth 1 :inherit ignore
                              :files (:defaults "elpaca-test.el" (:exclude "extensions"))
                              :build (:not elpaca-activate)))
(let* ((repo  (expand-file-name "elpaca/" elpaca-sources-directory))
       (build (expand-file-name "elpaca/" elpaca-builds-directory))
       (order (cdr elpaca-order))
       (default-directory repo))
  (add-to-list 'load-path (if (file-exists-p build) build repo))
  (unless (file-exists-p repo)
    (make-directory repo t)
    (condition-case-unless-debug err
        (if-let* ((buffer (pop-to-buffer-same-window "*elpaca-bootstrap*"))
                  ((zerop (apply #'call-process `("git" nil ,buffer t "clone"
                                                  ,@(when-let* ((depth (plist-get order :depth)))
                                                      (list (format "--depth=%d" depth) "--no-single-branch"))
                                                  ,(plist-get order :repo) ,repo))))
                  ((zerop (call-process "git" nil buffer t "checkout"
                                        (or (plist-get order :ref) "--"))))
                  (emacs (concat invocation-directory invocation-name))
                  ((zerop (call-process emacs nil buffer nil "-Q" "-L" "." "--batch"
                                        "--eval" "(byte-recompile-directory \".\" 0 'force)")))
                  ((require 'elpaca))
                  ((elpaca-generate-autoloads "elpaca" repo)))
            (progn (message "%s" (buffer-string)) (kill-buffer buffer))
          (error "%s" (with-current-buffer buffer (buffer-string))))
      ((error) (warn "%s" err) (delete-directory repo 'recursive))))
  (unless (require 'elpaca-autoloads nil t)
    (require 'elpaca)
    (elpaca-generate-autoloads "elpaca" repo)
    (let ((load-source-file-function nil)) (load "./elpaca-autoloads"))))
(add-hook 'after-init-hook #'elpaca-process-queues)
(elpaca `(,@elpaca-order))
#+end_src

* Emacs 本体配置
** 编辑行为

基本的编辑器行为设置：关闭自动保存/备份/锁文件以避免产生杂乱文件；
启用自动刷新、括号自动配对、选中即替换等现代编辑器习惯。

#+begin_src emacs-lisp
;; 当外部程序修改了文件时，自动刷新 buffer
(global-auto-revert-mode 1)

;; 关闭自动保存 (#file#)、备份文件 (file~) 和锁文件 (.#file)
(setq auto-save-default nil)
(setq make-backup-files nil)
(setq create-lockfiles nil)

;; 用 y/n 代替 yes/no 确认（替代已过时的 fset yes-or-no-p）
(setq use-short-answers t)

;; 启用自动括号配对（使用保守策略，避免在不合适的地方插入配对符号）
(setq electric-pair-inhibit-predicate 'electric-pair-conservative-inhibit)
(electric-pair-mode 1)

;; 记住最近打开的文件
(recentf-mode 1)
;; 保存 minibuffer 历史（M-x 命令历史、搜索历史等）
(savehist-mode 1)
;; 选中文本后直接输入即替换选中内容
(delete-selection-mode 1)

;; TAB 键优先缩进，若已缩进则触发补全
(setq tab-always-indent 'complete)
;; 关闭 text-mode 下的 ispell 补全（可用 cape-dict 替代）
(setq text-mode-ispell-word-completion nil)
;; 在 M-x 中隐藏当前 mode 不适用的命令
(setq read-extended-command-predicate #'command-completion-default-include-p)

** Tree-sitter

Emacs 31 把过去要靠 =treesit-auto= / 手写 =treesit-language-source-alist=
才能做的事收进了核心：

- =treesit-enabled-modes= 为 =t= 时，有 tree-sitter 变体的 major mode
  会自动切到 =*-ts-mode=（通过 =treesit-major-mode-remap-alist=）。
- =treesit-auto-install-grammar= 为 ='always= 时，缺语法库就直接编译安装，
  不再弹错退出。安装目录优先用 =treesit-extra-load-path= 里第一个可写目录。

原先依赖 casouri/tree-sitter-module 预编译 .so 的路径仍然保留，已有的
grammar 会继续被找到；没有的会由 Emacs 自己装到该目录或
=~/.emacs.d/tree-sitter/=。

#+begin_src emacs-lisp
(setq treesit-extra-load-path '("~/Repos/tree-sitter-module/dist/"))
(setq treesit-auto-install-grammar 'always)
(setq treesit-enabled-modes t)
#+end_src

** 缩进层级与彩虹括号

全局编程/配置 buffer 启用缩进竖线，空行保持连续，当前缩进层加亮。
Python / JSON / HTML 的 tree-sitter 模式还会区分当前作用域。
用字符 =│= 绘制，兼容 macOS、Windows 和终端，不改真实缩进。
圆括号 =()=、方括号 =[]=、花括号 ={}= 统一按嵌套深度着色，最外层
也有颜色；显式使用 Catppuccin 九色，兼顾 GUI / 终端和深浅背景，不依赖
GUI 才加载的主题。tree-sitter 上色完成后补绘，忽略字符串和注释。
这些都是纯 Elisp 包，由 Elpaca 安装，不改 flakes。

#+begin_src emacs-lisp
  (defun my/rainbow-delimiters-ts-fontify (beg end &rest _)
    "Apply rainbow brackets after tree-sitter fontification in this buffer."
    (when (bound-and-true-p rainbow-delimiters-mode)
      (save-excursion
        (save-match-data
          (save-restriction
            (goto-char beg)
            (rainbow-delimiters--propertize end))))))

  (defun my/rainbow-delimiters-setup-faces ()
    "Use distinct depth colors for (), [] and {} on GUI and color terminals."
    (let ((dark ["#f38ba8" "#fab387" "#f9e2af" "#a6e3a1" "#94e2d5"
                 "#74c7ec" "#89b4fa" "#b4befe" "#cba6f7"])
          (light ["#d20f39" "#fe640b" "#df8e1d" "#40a02b" "#179299"
                  "#209fb5" "#1e66f5" "#7287fd" "#8839ef"]))
      (dotimes (i 9)
        ;; User face settings survive later GUI theme changes and also apply
        ;; to terminal frames, where our GUI-only theme setup does not run.
        (custom-theme-set-faces
         'user
         `(,(intern (format "rainbow-delimiters-depth-%d-face" (1+ i)))
           ((((background dark)) (:foreground ,(aref dark i)))
            (t (:foreground ,(aref light i)))))))))

  (use-package rainbow-delimiters
    :demand t
    :custom
    (rainbow-delimiters-max-face-count 9)
    (rainbow-delimiters-outermost-only-face-count 0)
    :config
    (my/rainbow-delimiters-setup-faces)
    ;; TS modes bypass the traditional font-lock-keywords matcher used by
    ;; rainbow-delimiters.  Reapply it only in buffers where the mode is on.
    (with-eval-after-load 'treesit
      (advice-add 'treesit-font-lock-fontify-region :after
                  #'my/rainbow-delimiters-ts-fontify)))

  (defun my/code-indent-bars-enable ()
    "Enable guides and rainbow brackets in a programming/config buffer."
    ;; Enable rainbow first: indent-bars may immediately trigger fontification.
    (rainbow-delimiters-mode-enable)
    (indent-bars-mode 1))

  (use-package indent-bars
    :ensure (:repo "https://github.com/jdtsmith/indent-bars.git"
             :files (:defaults))
    :after rainbow-delimiters
    :demand t
    :custom
    (indent-bars-prefer-character t)
    (indent-bars-no-stipple-char ?│)
    (indent-bars-display-on-blank-lines t)
    (indent-bars-color '(font-lock-comment-face :blend 0.5))
    (indent-bars-color-by-depth
     '(:regexp "rainbow-delimiters-depth-\\([0-9]+\\)-face" :blend 0.4))
    (indent-bars-highlight-current-depth '(:blend 1.0))
    (indent-bars-highlight-selection-method 'on-bar)
    (indent-bars-treesit-support t)
    (indent-bars-treesit-scope
     '((python function_definition class_definition if_statement for_statement
               while_statement with_statement try_statement match_statement)
       (json object array)
       (html element script_element)))
    :hook ((prog-mode . my/code-indent-bars-enable)
           (conf-mode . my/code-indent-bars-enable)
           (html-ts-mode . my/code-indent-bars-enable))
    :config
    (require 'indent-bars-ts))

* 编程语言支持

Lua 用内置 =lua-ts-mode=（=treesit-enabled-modes=），不再装 =lua-mode=。

Python 沿用 =treesit-enabled-modes= 自动切换到 =python-ts-mode=，Eglot 连接
macOS/Linux 上由 Nix 声明安装的 =basedpyright-langserver=；Windows 上
手动安装 Python、basedpyright 和 Ghostel 所需二进制并加入 PATH 即可，
同一份 Elisp 配置不依赖 Nix。Python 解释器在 Windows 用 =python=，
其它系统用 =python3=。仅 Python buffer 中的 =C-c c c=
会保存并在右侧 Ghostel 运行当前 =.py=，同时将焦点移到输出窗口。
Meow 普通模式下用 =SPC c c=，编辑模式下用 =C-c c c=；这些绑定仅限 Python。
运行结束保留输出；输出窗口中单次 =C-c= 终止进程并关闭 buffer / 窗口。
=C-x k= 也会清理进程和窗口，不改变其它 Ghostel 的退出行为。

JSON 默认使用 =json-ts-mode=。JSON 和 Python 均启用 Combobulate，
Meow 普通模式下 =SPC ↑= 跳父级、=SPC ↓= 进入子级；编辑模式下对应
=C-c ↑= / =C-c ↓=。仅这两类 buffer 使用这些键，不改全局 leader。
Combobulate 为纯 Elisp，由 Elpaca 安装；tree-sitter 沿用现有语法库配置。
JSON / Python 中 =SPC s s=（编辑模式 =C-c s s=）在当前窗口显示整个
buffer 的 Combobulate 结构树（不截断为光标附近的几层）；=q= 返回。
这是结构列表，不是可以点击跳转的大纲。结构视图中按 =s= 导出 Markdown，
默认保存到原文件同目录的 =文件名.structure.md=（如 =1.structure.md=），
不询问路径；已有文件会确认覆盖。完整树放在 UTF-8 代码块中保留对齐。
生成视图时记录原文件路径，关闭中间阅读 buffer 后仍可导出。

HTML 默认使用 =html-ts-mode=。仅 HTML buffer 中的 =SPC j j=（编辑模式
=C-c j j=）在当前窗口打开内嵌 JSON 的独立只读 buffer，不创建文件，
不修改原 HTML。多段 JSON 时每次都选择 =application/json= 或
=application/ld+json= 等 JSON script。阅读 buffer 使用 =json-ts-mode= 和
Combobulate，可用 =SPC ↑= / =SPC ↓= 导航；=q= 关闭并返回 HTML。

=typst-ts-mode= 把 =define-compilation-mode= 写进了 autoloads，Elpaca 加载
该文件时 =compile= 往往还没就绪。关掉它的 autoloads，打开 =.typ= 再加载。

    "Force this Python session to stop before Ghostel releases its PTY."
    (when (and (processp my/python-output-process)
               (process-live-p my/python-output-process))
      (let* ((process my/python-output-process)
             (pid (or (process-get process 'ghostel--native-pid)
                      (process-id process))))
        (set-process-query-on-exit-flag process nil)
        (when (and (integerp pid) (> pid 0))
          (if (eq system-type 'windows-nt)
              ;; taskkill is part of Windows; /T includes child processes.
              (unless (and (executable-find "taskkill")
                           (zerop (call-process "taskkill" nil nil nil
                                                "/F" "/T" "/PID"
                                                (number-to-string pid))))
                (ignore-errors (signal-process pid 9)))
            ;; A local PTY child has its own process group.  Kill that group,
            ;; not just the Python parent, then let Ghostel's hook reap it.
            (unless (eq 0 (ignore-errors (signal-process (- pid) 9)))
              (ignore-errors (signal-process pid 9))))))))
