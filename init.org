* 新增功能快捷键说明书
:PROPERTIES:
:VISIBILITY: children
:END:

这里集中记录本配置新增的操作；下方各配置章节保留实现与详细说明。

- =SPC= 是空格键；=C-c= 表示 Ctrl+c；=M-x= 表示 Alt+x（macOS 取决于 Option/Meta 设置）。
- 表中的 =SPC …= 在 Meow *普通模式* 使用；对应 =C-c …= 在 *插入/编辑模式* 使用。
  这些是对应语言或 Notebook 的局部绑定，不是所有 buffer 都有的全局快捷键。
- =↑= / =↓= 指方向键，不是字母。组合键按顺序输入，不要把所有字母同时按下。

** JSON / HTML / Python：结构导航与阅读

适用于 =json-ts-mode=、=html-ts-mode=、=python-mode= / =python-ts-mode=，
包括 Notebook 的 Python cell 编辑 buffer。

| 普通模式 | 插入模式 | 功能 |
|----------+----------+------|
| =SPC ↑= | =C-c ↑= | 跳到父级结构 |
| =SPC ↓= | =C-c ↓= | 进入子级结构 |
| =SPC s s= | =C-c s s= | 当前窗口显示全文结构树，不限制为光标附近几层 |
| =SPC s p= | =C-c s p= | JSON：嵌套方框＋箭头图；HTML/Python：完整父级链 |

JSON 中默认显示 SVG 关系图：顶部居中显示源 HTML 文件与 script 标签；
每层保留 =["key"]= / =[14]= 方括号写法，外框标明字典/列表及项数，内框显示
少量真实子项，高亮继续通向当前值的子项，并用箭头连接各层。列表显示当前索引
附近的元素，字典只展示少量子项，不展开整个大 JSON。点击方框或子项跳回源 JSON，
可从中间层继续探索；点击顶部标签回原 HTML。终端不支持 SVG 时用文字方框回退。

长键只在图上缩略，完整内容在下方说明或鼠标提示里；即使键本身是 JSON 字符串，
也不把它误画成实际字典层级。=Tab= 选择下方节点链接，=Enter= 跳转；=g= 按当前
窗口宽度重排；拖动窗口、分屏或把图移入不同大小窗口时也会自动重排，窄窗口
改单列而非把文字缩得难以辨认，超出高度可滚动查看。默认不再铺 Python 代码，
=v= 才显示可选代码页，=g= 返回图示。
旧的表达式/网页解析/本地验证复制功能仍保留，但不是默认阅读内容。

HTML/Python 中仍显示名称、语法节点类型、起始行列和可用字段名，不省略
中间语法层；JSON 加 =C-u= 前缀也可查看这种原始语法链。所有视图独立只读，
=q= 返回原光标位置，不修改源文件。JSON 重复键覆盖的旧值会拒绝生成误导路径。

| 只读结构视图中的键 | 功能 |
|--------------------+------|
| =q= | 关闭视图，返回源 buffer 的原光标位置 |
| =s= | JSON 图导出 =文件名.path.svg=；其他结构视图导出 =文件名.structure.md=，覆盖前确认 |
| =v= / =g=（JSON 图） | 查看可选代码页 / 返回图并按窗口重排 |
| =y=（JSON 取值视图） | 复制完整的 =data[…]= 表达式 |
| =p=（JSON 取值视图） | 复制 =print(data[…])= |
| =c=（JSON 取值视图） | 复制网页解析代码，包含 BeautifulSoup、script 选择、json.loads 和 print；需已有 response |
| =l=（JSON 取值视图） | 复制读取原本地文件并打印值的完整代码 |

结构视图是文本列表，不是点击即可跳转的交互大纲。由 HTML 内嵌 JSON
阅读视图进入结构视图时，导出位置仍跟随原 HTML 文件。

** HTML / JSON：全文格式化与内嵌 JSON

| 适用范围 | 普通模式 | 插入模式 | 功能 |
|----------+----------+----------+------|
| HTML / JSON | =SPC f f= | =C-c f f= | 使用 Prettier 格式化全文 |
| Python / Notebook Python 编辑窗口 | =SPC f f= | =C-c f f= | 使用 Ruff 格式化全文 / 当前编辑单元，不执行或保存 |
| 仅 HTML | =SPC j j= | =C-c j j= | 当前窗口打开内嵌 JSON 的独立只读阅读视图 |

- 格式化在后台处理全文，即使存在选区或 narrowing；不自动保存，支持撤销，失败保留原文。
  期间若编辑了缓冲区，结果不会覆盖新编辑，需重新执行；再次调用会取消旧任务并重跑。
  可用 =M-x my/web-format-cancel= 取消，失败详情在 =*Prettier errors*=。
- 大于 256 KiB 或有超过 4000 字符长行的 HTML/JSON 使用轻量显示：关闭缩进线、
  彩虹括号及 Combobulate 额外高亮，长行横向滚动，保留原文、基础语法色和结构导航。
  格式化不再无限时逐字符 diff，也不强制全文件立即高亮。阈值见 =my/web-large-buffer-threshold=。
- 依赖 PATH 中的 =prettier= / =ruff=：Nix 系统由 flakes 安装，Windows 需手动安装。
- Python 仅运行 =ruff format=，不整理导入、不做 lint 修复；遵循项目 Ruff 配置和标准格式
  （例如调用中的关键字参数变为 =name=value=）。Notebook 只格式化 Python 编辑窗口，
  不修改普通 Org；退出编辑窗口时按原有机制回写。Ruff 错误见 =*Ruff errors*=。
- 内嵌 JSON 有多段时每次选择要查看的 script；原 HTML 不变，不创建 JSON 文件。
- JSON 阅读视图可以继续使用结构导航、全文树和父级链；按 =q= 返回 HTML。
  它保持只读，不能直接用格式化指令改写快照或原 HTML。

** Python 文件：运行与终端输出

| 位置 | 普通模式 | 插入模式 | 功能 |
|------+----------+----------+------|
| 本地 =.py= 文件 | =SPC c c= | =C-c c c= | 保存并运行当前文件，打开并聚焦右侧 Ghostel 输出窗口 |

在该 Python 输出窗口中，*单次* =C-c= 即终止会话并关闭输出 buffer / 窗口；
=C-x k= 关闭输出 buffer 时也会清理进程。程序自然结束后保留输出，方便阅读。
这些关闭行为仅限此运行器创建的终端，不改变普通 Ghostel。
Notebook 的 cell 编辑 buffer 使用下面的 cell 执行行为，不运行虚拟 =.py= 文件。

** Org Python Notebook：创建、执行与导航

先用 =M-x my/org-notebook-new= 新建 Notebook，或在已有 Org 文件中执行
=M-x my/org-notebook-mode= 切换。文件级 =:notebook:= 标签可在重开时自动启用。
以下按键仅用于启用 Notebook 模式的 *Org buffer*，普通 Org 与本配置文件不受影响。

| 普通模式 | 插入模式 | 功能 |
|----------+----------+------|
| =SPC n r= | =C-c n r= | 执行当前 cell，停留原处 |
| =SPC n x= | =C-c n x= | 执行并进入下一 cell，最后一个 cell 后自动新增 |
| =SPC n j= | =C-c n j= | 下一 cell |
| =SPC n k= | =C-c n k= | 上一 cell |
| =SPC n p= | =C-c n p= | 在正文光标处插入 Python cell；已在 cell 内则紧接其后新增 |
| =SPC n a= | =C-c n a= | 当前 cell 上方新增 Python cell |
| =SPC n b= | =C-c n b= | 当前 cell 下方新增 Python cell |
| =SPC n e= | =C-c n e= | 当前窗口进入 Python cell 编辑 buffer |
| =SPC n c= | =C-c n c= | 清除当前 cell 结果 |
| =SPC n s= | =C-c n s= | 确认后重启默认 Python 会话，清空共享变量 |

另有 =Ctrl+Enter= 执行并停留、=Shift+Enter= 执行后进入下一 cell；终端
若不能区分这两种组合键，就使用表中的 =n r= / =n x=。普通模式在 cell 上
直接按 =Enter= 也能进入 Python 编辑；插入模式的 Enter 仍用于 Org 换行。

Notebook 每个文件默认一个 Python 会话，cell 间共享变量。输出、stderr
及 Python 异常显示在原地 =#+RESULTS= 中，重跑替换旧结果；执行失败时
不自动跳转或新增 cell。Notebook 内执行免确认，仅对可信文件启用。

多线程 cell 会自动等待该 cell 新建的非 daemon 线程（包括它们创建的子线程）
结束后才完成结果收集。保留 Python 原始的 stdout/stderr 写入顺序，不对
=print= 加锁、不缓存重排、不按线程分组；允许线程自然交错、同一行内容穿插。
工作线程抛出的异常也显示在结果中，并阻止自动进入下一 cell。
不设等待超时；需要停止时按 =C-g=，会结束当前 Notebook 的 Python 会话、
清空变量，下一次执行自动启动新会话，避免旧线程继续输出并干扰后续 cell。
=daemon=True= 的后台线程不等待，其迟到的常规文本输出不追加到后续 cell。
线程池请使用 =with ThreadPoolExecutor(...) as pool:= 或显式 =shutdown()=，
否则空闲但未关闭的非 daemon 工作线程也会使 cell 保持执行中。

多进程也自动等待本 cell 启动的非 daemon 子进程退出，不改变系统默认的
=spawn= / =forkserver= 启动方式。worker 函数及所需导入放在同一个 cell
（或独立可导入的 Python 模块），启动进程/创建进程池的代码放在
~if __name__ == '__main__':~ 内；=Pool= / =ProcessPoolExecutor= 使用 =with= 关闭。
子进程原始 stdout/stderr 就地收集，不排序；异常和非零退出码会让 cell 失败。
跨 cell 定义的 =__main__= worker 不会被偷偷重放或序列化：请移到当前 cell
或可导入模块；父进程共享的 Notebook 变量也不是子进程的共享内存。
后台 daemon 子进程不保证结果归属，长驻后台程序建议通过 =.py= 终端运行。
=C-g= 会停止本次 Python 会话及其普通子进程，变量清空，下一次执行重建。

** Notebook：Python cell 编辑与返回

进入 cell 编辑后默认是 Meow 普通模式；按 =i= 开始输入。它使用 Python
语法高亮、补全和 Eglot/basedpyright；虚拟 =.py= 身份不会创建真实 Python 文件。

| 所处状态 | 操作 | 结果 |
|----------+------+------|
| cell 编辑，插入模式 | =Esc= | 先回到 Meow 普通模式，不退出编辑 |
| cell 编辑，普通模式 | =Esc= | 将代码写回 Org，退出 cell 编辑 |
| cell 编辑，普通模式 | =SPC c c= | 写回并返回 Org，执行该 cell |
| cell 编辑，插入模式 | =C-c c c= | 写回并返回 Org，执行该 cell |

** Python：代码片段（Tempel）

在 Python 文件或 Notebook 的 *Python cell 编辑 buffer* 中，插入模式输入
片段名后按 =Tab= 展开；也可从 Corfu 补全菜单选择标为片段的候选。
=Tab= 跳下一字段，=Shift+Tab= 跳上一字段，=M-Enter= 结束片段编辑。
没有片段可展开时，Tab 仍用于原来的缩进/补全。=M-x tempel-insert= 可列出片段。

| 片段名 | 展开内容 |
|--------+----------|
| =main= | ~if __name__ == '__main__':~，光标进入下一行缩进处 |
| =def= / =adef= | 普通 / async 函数，依次填写函数名、参数和函数体 |
| =class= / =classb= | 类 / 带父类的类 |
| =for= / =fori= | 遍历可迭代对象 / 遍历 range |
| =if= / =elif= / =while= | 条件、分支和循环 |
| =try= | try / except，填写异常类型、变量和处理代码 |
| =with= | with 上下文管理器 |
| =pr= | print 调用 |
| =imp= / =from= | import / from … import … |
| =ret= / =raise= | return / raise |

自动片段候选只在语句起始、行尾的缩写位置提供，不在字符串、注释、属性访问
或函数参数中干扰 Eglot。普通 Org 不启用；Notebook 中先用 Enter 进入 cell 编辑。

** Org：保留当前外观导出 PDF

| 普通模式 | 插入模式 | 功能 |
|----------+----------+------|
| =SPC e p= | =C-c e p= | 导出当前可见全文为可选中、可搜索文字的 PDF |

也可 =M-x my/org-export-visible-pdf=。默认保存为原 Org 文件旁的
=文件名.view.pdf=，已有文件会确认覆盖；加 =C-u= 前缀可选路径。
保留主题配色、代码高亮、标题字体、当前折叠及已显示的内联图片；折叠的内容
不会展开导出。它处理整个 buffer，不只截取当前屏幕，不运行 cell、不保存笔记。
A4 自动分页，长行会换行。若想导出完整内容，先自行展开全部标题/代码块。
需要本机 Chrome/Chromium（macOS 已安装）；可设置 =my/org-visible-pdf-browser-program=。
这是带可搜索文字的 HTML 打印版，不是截图，Org Modern 的边框、组合字形、
缩进装饰及分页位置可能与 Emacs 不完全相同；普通 =C-c C-e= 导出菜单不变。

** Meow：选词与快速加双引号

| 普通模式中的键 | 功能 |
|----------------+------|
| =w= | 选中光标下的单词 |
| =W=（Shift+w） | 选中光标下的符号，例如完整的 =interval_id=，包括下划线 |
| ="= | 给当前选区两端加双引号；没有选区则插入 =""= |
| =i= | 进入插入模式 |
| =Esc=（插入模式中） | 返回普通模式；Notebook cell 编辑中的两阶段退出见上表 |

例如选中 =interval_id= 后按 ="=，得到 ="interval_id"=；选中 =100:90=
后按 ="=，得到 ="100:90"=。双引号绑定不改变插入模式原有的自动配对行为。
=w= / =W= 按语言语法识别边界，*不等于严格按两端空白分隔*；例如
=foo.bar=、=100:90= 不保证由 =W= 一次完整选中。目前未添加空白分隔选取键。

* 包管理器 (Elpaca)

Elpaca 是一个现代化的 Emacs 包管理器，支持异步安装、懒加载和从 Git 仓库
直接拉取包。以下为官方推荐的 bootstrap 代码，首次启动时会自动克隆并编译
Elpaca 本身。

=elpaca-core-date= 必须在加载 Elpaca 之前设定。当前 Elpaca 内置的发行日
期表只到 30.2，在 Emacs 31 上不设这个值会报
=Unable to determine elpaca-core-date=。31.1 的官方发布日是 2026-08-24。

#+begin_src emacs-lisp
(setq elpaca-core-date '(20260824))

(defvar elpaca-installer-version 0.12)
(defvar elpaca-directory (expand-file-name "elpaca/" user-emacs-directory))
(defvar elpaca-builds-directory (expand-file-name "builds/" elpaca-directory))
(defvar elpaca-sources-directory (expand-file-name "sources/" elpaca-directory))
(defvar elpaca-order '(elpaca :repo "https://github.com/progfolio/elpaca.git"
                              :ref nil :depth 1 :inherit ignore
                              :files (:defaults "elpaca-test.el" (:exclude "extensions"))
                              :build (:not elpaca-activate)))
(let* ((repo  (expand-file-name "elpaca/" elpaca-sources-directory))
       (build (expand-file-name "elpaca/" elpaca-builds-directory))
       (order (cdr elpaca-order))
       (default-directory repo))
  (add-to-list 'load-path (if (file-exists-p build) build repo))
  (unless (file-exists-p repo)
    (make-directory repo t)
    (condition-case-unless-debug err
        (if-let* ((buffer (pop-to-buffer-same-window "*elpaca-bootstrap*"))
                  ((zerop (apply #'call-process `("git" nil ,buffer t "clone"
                                                  ,@(when-let* ((depth (plist-get order :depth)))
                                                      (list (format "--depth=%d" depth) "--no-single-branch"))
                                                  ,(plist-get order :repo) ,repo))))
                  ((zerop (call-process "git" nil buffer t "checkout"
                                        (or (plist-get order :ref) "--"))))
                  (emacs (concat invocation-directory invocation-name))
                  ((zerop (call-process emacs nil buffer nil "-Q" "-L" "." "--batch"
                                        "--eval" "(byte-recompile-directory \".\" 0 'force)")))
                  ((require 'elpaca))
                  ((elpaca-generate-autoloads "elpaca" repo)))
            (progn (message "%s" (buffer-string)) (kill-buffer buffer))
          (error "%s" (with-current-buffer buffer (buffer-string))))
      ((error) (warn "%s" err) (delete-directory repo 'recursive))))
  (unless (require 'elpaca-autoloads nil t)
    (require 'elpaca)
    (elpaca-generate-autoloads "elpaca" repo)
    (let ((load-source-file-function nil)) (load "./elpaca-autoloads"))))
(add-hook 'after-init-hook #'elpaca-process-queues)
(elpaca `(,@elpaca-order))
#+end_src

** use-package 集成

让 =use-package= 默认使用 =:ensure t=，并启用 Elpaca 作为 use-package 的后端。

#+begin_src emacs-lisp
(setq use-package-always-ensure t)

(elpaca elpaca-use-package
  (elpaca-use-package-mode)
  (setq elpaca-use-package-by-default t))

(elpaca-wait)

;; compat / transient 会被 ai-code 一类包当依赖。
;; 先激活，避免 compat 被 ghostel 提前加载，也避免

(use-package transient :ensure (:wait t) :demand t)

* Emacs 本体配置
** 编辑行为

基本的编辑器行为设置：关闭自动保存/备份/锁文件以避免产生杂乱文件；
启用自动刷新、括号自动配对、选中即替换等现代编辑器习惯。

#+begin_src emacs-lisp
;; 当外部程序修改了文件时，自动刷新 buffer
(global-auto-revert-mode 1)

;; 关闭自动保存 (#file#)、备份文件 (file~) 和锁文件 (.#file)
(setq auto-save-default nil)
(setq make-backup-files nil)
(setq create-lockfiles nil)

;; 用 y/n 代替 yes/no 确认（替代已过时的 fset yes-or-no-p）
(setq use-short-answers t)

;; 启用自动括号配对（使用保守策略，避免在不合适的地方插入配对符号）
(setq electric-pair-inhibit-predicate 'electric-pair-conservative-inhibit)
(electric-pair-mode 1)

;; 记住最近打开的文件
(recentf-mode 1)
;; 保存 minibuffer 历史（M-x 命令历史、搜索历史等）
(savehist-mode 1)
;; 选中文本后直接输入即替换选中内容
(delete-selection-mode 1)

;; TAB 键优先缩进，若已缩进则触发补全
(setq tab-always-indent 'complete)
;; 关闭 text-mode 下的 ispell 补全（可用 cape-dict 替代）
(setq text-mode-ispell-word-completion nil)
;; 在 M-x 中隐藏当前 mode 不适用的命令
(setq read-extended-command-predicate #'command-completion-default-include-p)
#+end_src

** Tree-sitter

Emacs 31 把过去要靠 =treesit-auto= / 手写 =treesit-language-source-alist=
才能做的事收进了核心：

- =treesit-enabled-modes= 为 =t= 时，有 tree-sitter 变体的 major mode
  会自动切到 =*-ts-mode=（通过 =treesit-major-mode-remap-alist=）。
- =treesit-auto-install-grammar= 为 ='always= 时，缺语法库就直接编译安装，
  不再弹错退出。安装目录优先用 =treesit-extra-load-path= 里第一个可写目录。

** 自适应原生 modeline

不依赖外部 modeline 包。每个窗口按自己的实际宽度排版，优先显示
Meow 状态、修改/只读标记、文件名、=行:列=；文件名过长时从中间缩略。
有余量才加入模式、Notebook/cell、LSP、进程/诊断、Git、编码与滚动位置。
=*=: 已修改，=R=: 只读，=-=: 未修改。悬浮 modeline 可查看完整信息。

#+begin_src emacs-lisp
  (defun my/modeline-fit (text width)
    "Fit TEXT in WIDTH display columns, preserving both ends when truncated."
    (setq width (max 0 width))
    (cond ((<= (string-width text) width) text)
          ((= width 0) "")
          ((= width 1) "…")
          (t
           (let* ((tail (min 8 (/ (1- width) 3)))
                  (head (- width tail 1))
                  (total (string-width text)))
             (concat (truncate-string-to-width text head)
                     "…"
                     (truncate-string-to-width text total (- total tail)))))))

  (defun my/modeline-name ()
    "Return a useful name, including for virtual notebook/JSON/tree views."
    (let ((source
           (cond
            ((and (bound-and-true-p my/org-notebook-cell-edit-mode)
                  (fboundp 'org-src-source-buffer))
             (ignore-errors (org-src-source-buffer)))
            ((bound-and-true-p my/html-json-source-buffer))
            ((bound-and-true-p my/combobulate-structure-source)))))
      (if (buffer-live-p source)
          (with-current-buffer source
            (if buffer-file-name (file-name-nondirectory buffer-file-name) (buffer-name)))
        (if buffer-file-name (file-name-nondirectory buffer-file-name) (buffer-name)))))

  (defun my/modeline-mode-label ()
    (concat
     (pcase major-mode
       ((or 'python-mode 'python-ts-mode) "Py")
       ('json-ts-mode "JSON") ('html-ts-mode "HTML")
       ('org-mode "Org") ('emacs-lisp-mode "Elisp")
       (_ (string-remove-suffix "-mode" (symbol-name major-mode))))
     (cond ((bound-and-true-p my/org-notebook-cell-edit-mode) ":Cell")
           ((bound-and-true-p my/org-notebook-mode) ":NB")
           ((bound-and-true-p my/combobulate-structure-view-mode) ":Tree")
           (t ""))))

  (defun my/modeline-help (window _object _position)
    "Show native full status on demand rather than crowding narrow windows."
    (when (window-live-p window)
      (with-current-buffer (window-buffer window)
        (format "%s\n%s\n%s\n%s\n*: modified · R: read-only · position: line:column (column starts at 0)"
                (buffer-name) (or buffer-file-name default-directory)
                (format-mode-line mode-line-modes nil window)
                (format-mode-line '(vc-mode "  " mode-line-process "  " "%Z") nil window)))))

  (defun my/modeline-layout (width state flags name position extras)
    "Render a single line, reserving POSITION and identity before EXTRAS."
    (let* ((budget (max 1 (- width 2)))
           (prefix (concat (when state
                             (propertize (if (< width 28) state (concat "[" state "]"))
                                         'face 'mode-line-emphasis))
                           (propertize flags 'face (if (string-match-p "[*R]" flags)
                                                       'warning 'mode-line))
                           " "))
           (minimum-name (min 12 (string-width name)))
           (selected ""))
      (dolist (extra extras)
        (when (and (stringp extra) (not (string-empty-p extra))
                   (<= (+ (string-width prefix) minimum-name
                          (string-width selected) 1 (string-width extra)
                          1 (string-width position)) budget))
          (setq selected (concat selected " " extra))))
      (let* ((name-width (max 1 (- budget (string-width prefix)
                                   (string-width selected) (string-width position) 1)))
             (fitted (propertize (my/modeline-fit name name-width)
                                'face 'mode-line-buffer-id))
             (gap (max 1 (- budget (string-width prefix) (string-width fitted)
                            (string-width selected) (string-width position))))
             (line (concat " " prefix fitted selected (make-string gap ?\s) position " ")))
        ;; Only impossibly small windows (< identity + position) need a final clip.
        (propertize (if (> (string-width line) width) (my/modeline-fit line width) line)
                    'help-echo #'my/modeline-help))))

  (defun my/modeline-render ()
    "Use the window currently being rendered, not a fixed frame-width threshold."
    (let* ((window (selected-window))
           (width (window-total-width window))
           (state (cond ((bound-and-true-p meow-keypad-mode) "K")
                        ((bound-and-true-p meow-beacon-mode) "B")
                        ((bound-and-true-p meow-insert-mode) "I")
                        ((bound-and-true-p meow-normal-mode) "N")
                        ((bound-and-true-p meow-motion-mode) "M")))
           (flags (concat (if (buffer-modified-p) "*" "-")
                          (when buffer-read-only "R")))
           (name (replace-regexp-in-string "[\n\r\t]" " " (my/modeline-name)))
           (position (format-mode-line "%l:%c" nil window))
           (extras (list (my/modeline-fit (my/modeline-mode-label) 18)
                         (when (bound-and-true-p eglot--managed-mode) "LSP")
                         (when (>= width 60)
                           (my/modeline-fit (string-trim (format-mode-line mode-line-process nil window)) 22))
                         (when (and (>= width 70) (bound-and-true-p vc-mode))
                           (my/modeline-fit (string-trim (format-mode-line vc-mode nil window)) 20))
                         (when (>= width 80) (format-mode-line "%Z" nil window))
                         (when (>= width 90) (string-trim (format-mode-line "%p" nil window))))))
      ;; Escape literal % in filenames/status; native mode-line formatting will
      ;; interpret the returned string once more.  No packages are loaded here.
      (replace-regexp-in-string
       "%" "%%" (my/modeline-layout width state flags name position extras) t t)))

(defun my/org-visible-pdf-image (display)
  "Embed a displayed image without depending on external file URLs."
  (let* ((spec (cdr display))
         (file (plist-get spec :file))
         (type (or (plist-get spec :type) (and file (intern (downcase (or (file-name-extension file) ""))))))

(defun my/org-visible-pdf-face (face)
  "Resolve live theme inheritance before htmlfontify serializes a face."
  (let ((temporary 'my/org-visible-pdf--resolved-face))
    (unless (facep temporary) (make-face temporary))
    (face-spec-reset-face temporary)
    (set-face-attribute temporary nil :inherit 'default)
    (cond
     ((facep face) (set-face-attribute temporary nil :inherit face))
     ((keywordp (car-safe face))
      (let (attributes)
        (while face
          (let ((key (pop face)) (value (pop face)))
            (when (assq key face-attribute-name-alist)
              (setq attributes (append attributes (list key value))))))
        (apply #'set-face-attribute temporary nil attributes)))
     ((consp face) (set-face-attribute temporary nil :inherit face)))
    (cl-loop for attribute in '(:family :foreground :background :height :weight :slant
                               :underline :overline :strike-through :box)
             append (list attribute (face-attribute temporary attribute nil 'default)))))

(defun my/org-visible-pdf-html ()
  "Return HTML for the entire visible Org buffer, preserving current folds."
  (require 'htmlfontify)
  (let* ((title (buffer-name))
         (background (face-attribute 'default :background nil t))
         (foreground (face-attribute 'default :foreground nil t))
         (tabs tab-width)
         (snapshot (generate-new-buffer " *org-visible-pdf-snapshot*"))
         (faces (make-hash-table :test #'equal))
         (hfy-optimizations '(skip-refontification keep-overlays))
         (hfy-page-header
          (lambda (_file style)
            (format "<!doctype html><html><head><meta charset=\"utf-8\"><title>%s</title>%s<style>
@page { size: A4; margin: 12mm; }
html, body { background: %s; color: %s; margin: 0; print-color-adjust: exact; -webkit-print-color-adjust: exact; }
pre { white-space: pre-wrap; overflow-wrap: anywhere; tab-size: %d; margin: 0; }
img { max-width: 100%%; height: auto; break-inside: avoid; }
</style></head><body>" (my/org-visible-pdf-escape title) style background foreground tabs)))
         (hfy-page-footer (lambda (&rest _) "</body></html>"))
         images html)
    (unwind-protect
        (progn
          (save-restriction
            (widen)
            (font-lock-ensure)
            (let ((position (point-min)) (end (point-max)) previous-display)
              (while (< position end)
                (let* ((next (next-char-property-change position end))
                       (display (get-char-property position 'display))
                       (hidden (invisible-p position))
                       (raw-face (hfy-face-at position))
                       (face (or (gethash raw-face faces)
                                 (puthash raw-face (my/org-visible-pdf-face raw-face) faces)))
                       (text
                        (cond
                         ((or (org-fold-folded-p position)
                              (and hidden (not (eq (car-safe display) 'image))))
                          ;; A folded subtree may hide its leading newline.
                          (when (string-match-p "\n" (buffer-substring-no-properties position next)) "\n"))
                         ((and display (eq display previous-display)) "")
                         ((stringp display) display)
                         ((eq (car-safe display) 'image)
                          (let ((token (format "ORG-PDF-IMAGE-%s" (gensym))))
                            (push (cons token (my/org-visible-pdf-image display)) images)
                            token))
                         ((and (eq (car-safe display) 'space) (numberp (plist-get (cdr display) :width)))
                          (make-string (max 0 (round (plist-get (cdr display) :width))) ?\s))
                         (t (buffer-substring-no-properties position next)))))
                  (when text
                    (with-current-buffer snapshot
                      (insert (propertize (substring-no-properties text) 'face face))))
                  (setq previous-display display position next)))))
          (with-current-buffer snapshot
            (setq html (htmlfontify-buffer nil title)))
          (with-current-buffer html
            (dolist (image images)
              (goto-char (point-min))
              (unless (search-forward (car image) nil t) (error "Image placeholder was lost"))
              (replace-match (cdr image) t t))
            (buffer-string)))
      (when (buffer-live-p snapshot) (kill-buffer snapshot))
      (when (buffer-live-p html) (kill-buffer html)))))

(defun my/org-export-visible-pdf (&optional file)

* Org Python Notebook

使用内置 =ob-python=，不是 Jupyter kernel，也不读写 =.ipynb=。
=M-x my/org-notebook-new= 新建 =.org= notebook；=:notebook:= 文件标签
会让它重开时自动启用。也可在现有 Org 中手动切换 =my/org-notebook-mode=。
普通 Org 笔记和 =init.org= 不启用这些按键。Python 默认每个文件一个会话，
cell 间共享变量，结果就地替换。仅 notebook 内执行免确认，普通 Org 的
执行确认设置不变；只对可信 notebook 使用此模式。
Python 异常及 stderr 显示在当前 cell 的 =#+RESULTS= 中；失败时不自动
跳转或新增 cell，修正后重跑会替换旧的错误结果。
多线程执行等待本 cell 新建的非 daemon 线程完成后再结束，并收集工作线程
异常。输出直接转发 Python 原始 stdout/stderr，不对 =print= 加锁、不整行
整理、不排序或按线程分组；顺序与行内穿插由线程实际调度决定。
不设置线程等待超时；=C-g= 会结束当前 Python 会话（变量清空），下次执行重建。
后台 daemon 线程不等待，执行结束后的常规文本输出不污染下一 cell；线程池
应使用 =with= 或显式 =shutdown()= 关闭，否则 Notebook 会一直等其工作线程。
多进程使用当前 cell 的真实源文件作为可导入入口，保留系统的 =spawn= /
=forkserver=，自动等待新建的非 daemon 子进程退出并检查退出码。worker
及所需导入须在同一 cell 或可导入模块中，启动代码放在
~if __name__ == '__main__':~ 下；进程池用 =with= 关闭。不自动重放过去的
cell，不把父进程变量假装成共享内存；daemon 后台子进程建议改用独立脚本。

* 模态编辑 (Meow)

Meow 是一个轻量的模态编辑框架，类似 Vim 但更贴合 Emacs 哲学。
使用 QWERTY 布局，hjkl 移动，支持选择优先 (selection-first) 的编辑模式。
普通模式选中文本后按 ="=，用内置 =insert-pair= 包上双引号；不影响插入
模式的自动配对。未选中时按 ="= 则插入一对空引号。

* 编程语言支持

Lua 用内置 =lua-ts-mode=（=treesit-enabled-modes=），不再装 =lua-mode=。

Python 沿用 =treesit-enabled-modes= 自动切换到 =python-ts-mode=，Eglot 连接
macOS/Linux 上由 Nix 声明安装的 =basedpyright-langserver=；Windows 上
手动安装 Python、basedpyright 和 Ghostel 所需二进制并加入 PATH 即可，
同一份 Elisp 配置不依赖 Nix。Python 解释器在 Windows 用 =python=，
其它系统用 =python3=。仅 Python buffer 中的 =C-c c c=
会保存并在右侧 Ghostel 运行当前 =.py=，同时将焦点移到输出窗口。
Meow 普通模式下用 =SPC c c=，编辑模式下用 =C-c c c=；这些绑定仅限 Python。
运行结束保留输出；输出窗口中单次 =C-c= 终止进程并关闭 buffer / 窗口。
=C-x k= 也会清理进程和窗口，不改变其它 Ghostel 的退出行为。

JSON 默认使用 =json-ts-mode=。JSON、HTML 和 Python 均启用 Combobulate，
Meow 普通模式下 =SPC ↑= 跳父级、=SPC ↓= 进入子级；编辑模式下对应
=C-c ↑= / =C-c ↓=。仅这三类 buffer 使用这些键，不改全局 leader。
Combobulate 为纯 Elisp，由 Elpaca 安装；tree-sitter 沿用现有语法库配置。
JSON / HTML / Python 中 =SPC s s=（编辑模式 =C-c s s=）在当前窗口显示整个
buffer 的 Combobulate 结构树（不截断为光标附近的几层）；=q= 返回。
这是结构列表，不是可以点击跳转的大纲。结构视图中按 =s= 导出 Markdown，
默认保存到原文件同目录的 =文件名.structure.md=（如 =1.structure.md=），
不询问路径；已有文件会确认覆盖。完整树放在 UTF-8 代码块中保留对齐。
生成视图时记录原文件路径，关闭中间阅读 buffer 后仍可导出。

=SPC s p=（编辑模式 =C-c s p=）在 JSON 中显示方括号节点、嵌套容器和箭头，
顶部居中显示可点击的原 HTML 标签，窗口大小变化时自动重排。点击节点返回 JSON 对应位置；=g= 重排，
=v= 查看可选代码，=s= 导出 SVG。渲染器在 =lisp/my-json-diagram.el=，纯内置 SVG，
不需要 Graphviz 或浏览器渲染。=y= / =p= 与 =c= / =l= 仍可复制表达式、print、
网页解析及本地验证代码。HTML/Python 保留原父级链；JSON 加 =C-u= 前缀可查看
原语法链。=q= 返回原 buffer 原光标位置。

HTML 默认使用 =html-ts-mode=。仅 HTML buffer 中的 =SPC j j=（编辑模式
=C-c j j=）在当前窗口打开内嵌 JSON 的独立只读 buffer，不创建文件，
不修改原 HTML。多段 JSON 时每次都选择 =application/json= 或
=application/ld+json= 等 JSON script。阅读 buffer 使用 =json-ts-mode= 和
Combobulate，可用 =SPC ↑= / =SPC ↓= 导航；=q= 关闭并返回 HTML。

HTML / JSON 中 =SPC f f=（编辑模式 =C-c f f=）使用后台 Prettier 格式化全文，
即使当前有选区或 narrowing 也处理整个文件。不自动保存，支持撤销；格式化
失败或期间又编辑了原文时不会覆盖。差异比较限时，大文件直接批量替换并使用
轻量显示，不全量强制高亮。只读 JSON 快照仍保持只读。Prettier 通过 flakes 安装，
Windows 需手动安装并放入 PATH。

=typst-ts-mode= 把 =define-compilation-mode= 写进了 autoloads，Elpaca 加载
该文件时 =compile= 往往还没就绪。关掉它的 autoloads，打开 =.typ= 再加载。

  (defvar-local my/web-format-process nil
    "Current asynchronous Prettier/Ruff job for this buffer.")

  (defun my/web-format-label (process)
    (or (process-get process 'my/formatter-label) "Prettier"))

  (defun my/web-format-cancel ()
    "Cancel this buffer's pending formatter without applying partial output."
    (interactive)
    (let ((process my/web-format-process))
      (setq my/web-format-process nil)
      (when process (process-put process 'my/web-format-state 'cancelled))
      (when (and process (process-live-p process)) (delete-process process))))

  (defun my/web-format-finished (source tick output errors process _event)
    "Apply a completed formatter only to an unchanged live SOURCE."
    (when (memq (process-status process) '(exit signal))
      (unwind-protect
          (when (and (buffer-live-p source)
                     (eq process (buffer-local-value 'my/web-format-process source)))
            (with-current-buffer source
              (setq my/web-format-process nil)
              (condition-case err
                  (cond
                   ((not (and (eq (process-status process) 'exit)
                              (zerop (process-exit-status process))))
                    (error "%s" (with-current-buffer errors (string-trim (buffer-string)))))
                   ((/= tick (buffer-chars-modified-tick))
                    (process-put process 'my/web-format-state 'stale)
                    (message "%s: %s changed while formatting; nothing overwritten, please retry" (my/web-format-label process) (buffer-name)))
                   (t
                    (barf-if-buffer-read-only)
                    (save-restriction
                      (widen)
                      (when (derived-mode-p 'html-ts-mode 'json-ts-mode) (my/web-maybe-lighten))
                      (let ((position (point))
                            (inhibit-redisplay t))
                        (atomic-change-group
                          ;; Never run an unbounded character diff.  Large
                          ;; buffers use one bulk replacement, not thousands
                          ;; of edits/hook calls for whitespace changes.
                          (replace-buffer-contents output
                                                   (if (bound-and-true-p my/web-lightweight-p) 0 0.05)))
                        (goto-char (min (point-max) (max (point-min) position))))
                      (when font-lock-mode (font-lock-flush)))
                    (process-put process 'my/web-format-state 'done)
                    (message "%s: formatted %s (not saved)" (my/web-format-label process) (buffer-name))))
                (error
                 (process-put process 'my/web-format-state 'error)
                 (let ((errors-name (format "*%s errors*" (my/web-format-label process))))
                   (with-current-buffer (get-buffer-create errors-name)
                     (let ((inhibit-read-only t))
                       (erase-buffer)
                       (insert (error-message-string err))
                       (special-mode)))
                   (message "%s failed; original buffer retained. See %s" (my/web-format-label process) errors-name))))))
        (let ((kill-buffer-query-functions nil))
          (dolist (buffer (list output errors))
            (when (buffer-live-p buffer) (kill-buffer buffer)))))))

  (defun my/web-format-buffer ()
    "Format HTML/JSON with Prettier or Python with Ruff, without saving."
    (interactive)
    (barf-if-buffer-read-only)
    (let* ((parser (cond ((derived-mode-p 'html-ts-mode) "html")
                         ((derived-mode-p 'json-ts-mode) "json")
                         ((derived-mode-p 'python-mode 'python-ts-mode) "python")
                         (t (user-error "Use this command in an HTML, JSON or Python buffer"))))
           (python (equal parser "python"))
           (tool (if python "ruff" "prettier"))
           (label (if python "Ruff" "Prettier"))
           (program (or (executable-find tool)
                        (user-error "%s is not on PATH; install it via flakes (Windows: install manually)" label)))
           (filename (or buffer-file-name (expand-file-name (concat "untitled." (if python "py" parser)))))
           (source (current-buffer))
           (tick (buffer-chars-modified-tick))
           (output (generate-new-buffer " *prettier-output*"))
           (errors (generate-new-buffer " *prettier-stderr*"))
           process)
      (my/web-format-cancel)
      (condition-case err
          (progn
            (setq process
                  (make-process
                   :name tool :buffer output :stderr errors :noquery t
                   :connection-type 'pipe :coding '(utf-8-unix . utf-8-unix)
                   :command (if python (list program "format" "--stdin-filename" filename "-")
                              (list program "--parser" parser "--stdin-filepath" filename))
                   :sentinel (apply-partially #'my/web-format-finished source tick output errors)))
            (setq my/web-format-process process)
            (process-put process 'my/formatter-label label)
            (process-put process 'my/web-format-state 'running)
            (add-hook 'kill-buffer-hook #'my/web-format-cancel nil t)
            (save-restriction
              (widen)
              (process-send-region process (point-min) (point-max)))
            (process-send-eof process)
            (message "%s: formatting %s in background…" label (buffer-name))
            process)
        (error
         (setq my/web-format-process nil)
         (when (and process (process-live-p process)) (delete-process process))
         (dolist (buffer (list output errors))
           (when (buffer-live-p buffer) (kill-buffer buffer)))
         (signal (car err) (cdr err))))))

  (defun my/html-script-attribute (tag name)
    "Return decoded attribute NAME of the tree-sitter start TAG, or nil."
    (require 'xml)
    (let (value)
      (dotimes (i (treesit-node-child-count tag t))
        (let ((attribute (treesit-node-child tag i t)))
          (when (and (equal (treesit-node-type attribute) "attribute")
                     (string-equal
                      (downcase (treesit-node-text
                                 (treesit-node-child attribute 0 t) t))
                      name))
            (let ((node (treesit-node-child attribute 1 t)))
              (when node
                (when (equal (treesit-node-type node) "quoted_attribute_value")
                  (setq node (treesit-node-child node 0 t)))
                (when node
                  (let ((raw (treesit-node-text node t)))
                    (setq value (condition-case nil (xml-substitute-special raw)
                                  (error raw))))))))))
      value))

  (defun my/html-json-scripts ()
    "List JSON script entries with :label, :beg and :end in this HTML buffer."
    (let (entries seen)
      (dolist (script (treesit-query-capture
                       (treesit-buffer-root-node 'html)
                       '((script_element) @script) nil nil t))
        (let* ((tag (treesit-node-child script 0 t))
               (raw-type (or (my/html-script-attribute tag "type") ""))
               (type (downcase (string-trim (car (split-string raw-type ";")))))
               (id (my/html-script-attribute tag "id"))
               (selector-index
                (cl-count-if (lambda (item)
                               (if id (equal id (car item))
                                 (equal raw-type (cdr item)))) seen))
               body)
          (push (cons id raw-type) seen)
          (when (or (equal type "application/json")
                    (string-match-p "\\`application/[^;]+\\+json\\'" type))
            (dotimes (i (treesit-node-child-count script t))
              (let ((child (treesit-node-child script i t)))
                (when (equal (treesit-node-type child) "raw_text")
                  (setq body child))))
            (when body
              (push (list :label (format "%s · %s · line %d"
                                        (if id (concat "#" id) "script") type
                                        (line-number-at-pos (treesit-node-start script)))
                          :beg (treesit-node-start body)
                          :end (treesit-node-end body)
                          :id id :type raw-type :selector-index selector-index
                          :line (line-number-at-pos (treesit-node-start script))
                          :tag-start (treesit-node-start tag)
                          :tag (treesit-node-text tag t))
                    entries)))))
      (nreverse entries)))

  (defun my/html-view-json ()
    "Choose an embedded JSON script and view a read-only copy in this window.
Always prompt if multiple scripts exist, regardless of point.  q returns
 to the source HTML.  No file is created and the HTML is not modified."
    (interactive)
    (unless (derived-mode-p 'html-ts-mode)
      (user-error "Run this command in an HTML tree-sitter buffer"))
    (let* ((source (current-buffer))
           (tick (buffer-chars-modified-tick))
           (entries (my/html-json-scripts))
           (entry (if (= (length entries) 1)
                      (car entries)
                    (when entries
                      (let ((choices (mapcar (lambda (item)
                                               (cons (plist-get item :label) item))
                                             entries)))
                        (cdr (assoc (completing-read "JSON script: " choices nil t)
                                    choices)))))))
      (unless entry (user-error "No embedded JSON script found"))
      (unless (= tick (buffer-chars-modified-tick))
        (user-error "HTML changed while selecting; run this command again"))
      (let ((origin (append (copy-sequence entry)
                            (list :file buffer-file-name :buffer-name (buffer-name)
                                  :modified (buffer-modified-p))))
            (text (buffer-substring-no-properties
                   (plist-get entry :beg) (plist-get entry :end))))
        (condition-case err
            (json-parse-string text)
          (error (user-error "Invalid JSON in %s: %s"
                             (plist-get entry :label) (error-message-string err))))
        (let ((view (generate-new-buffer
                     (format "*JSON: %s · %s*" (buffer-name) (plist-get entry :label)))))
          (condition-case err
              (progn
                (with-current-buffer view
                  (insert text)
                  (json-ts-mode)
                  ;; This fresh buffer has no HTML properties.  Let JIT color
                  ;; only the visible region instead of eagerly fontifying all.
                  (setq-local my/html-json-source-buffer source
                              my/html-json-origin origin
                              buffer-read-only t
                              buffer-offer-save nil)
                  (my/html-json-view-mode 1)
                  (set-buffer-modified-p nil)
                  (goto-char (point-min)))
                (switch-to-buffer view))
            ((error quit)
             (when (buffer-live-p view) (kill-buffer view))
             (signal (car err) (cdr err))))))))

    "Follow JSON/structure source links from BUFFER to its original file."
    (let (seen file)

  (defun my/combobulate-structure-export-markdown ()
    "Export the complete structure beside its original file, without a path prompt."
    (interactive)
    (unless (and my/combobulate-structure-view-mode
                 my/combobulate-structure-origin-file)
      (user-error "This structure view has no original file to export beside"))
    (let* ((file (concat (file-name-sans-extension
                         my/combobulate-structure-origin-file)
                        ".structure.md"))
           (text (save-restriction
                   (widen)
                   (buffer-substring-no-properties (point-min) (point-max))))
           (longest 0)
           (start 0))
      ;; A key/node label could contain backticks; choose a longer fence so
      ;; no tree text can accidentally close the Markdown code block.
      (while (string-match "`+" text start)
        (setq longest (max longest (- (match-end 0) (match-beginning 0)))
              start (match-end 0)))
      (unless (or (not (file-exists-p file))
                  (y-or-n-p (format "Overwrite %s? " file)))
        (user-error "Export cancelled"))
      (let ((fence (make-string (max 3 (1+ longest)) ?`))
            (coding-system-for-write 'utf-8-unix))
        (with-temp-file file
          (insert "# Buffer structure\n\n" fence "text\n" text)
          (unless (string-suffix-p "\n" text) (insert "\n"))
          (insert fence "\n")))
      (message "Structure exported to %s" file)))

    "Describe every syntax node from point to the main parser's root."
    (save-restriction
      (widen)

             (root (combobulate-root-node))
             (node (or (and (< position (treesit-node-end root))

             lines)
        (while node
          (let* ((type (treesit-node-type node))
                 (label (substring-no-properties

                 (leaf (when (zerop (treesit-node-child-count node))
                         (replace-regexp-in-string

                           (treesit-node-start node)
                           (min (treesit-node-end node) (+ (treesit-node-start node) 80)))))))

                              (concat " = " leaf) "")

  (defun my/json-python-reference-info ()
    "Compute an executable data[...] path at point without drawing a full tree."
    (save-restriction
      (widen)
      (let* ((root (treesit-buffer-root-node 'json))
             (node (or (and (< (point) (treesit-node-end root))
                            (treesit-node-descendant-for-range root (point) (1+ (point)) t))
                       root))
             (types '("object" "array" "string" "number" "true" "false" "null" "pair" "document"))
             parts)
        (when (treesit-node-check root 'has-error)
          (user-error "Fix the JSON syntax before copying a Python reference"))
        (while (and node (not (member (treesit-node-type node) types)))
          (setq node (treesit-node-parent node)))
        (when (equal (treesit-node-type node) "document")
          (setq node (treesit-node-child node 0 t)))
        (when (equal (treesit-node-type node) "pair")
          (setq node (treesit-node-child-by-field-name node "value")))
        ;; A key denotes that pair's value, not a string to index into.
        (when-let* ((parent (treesit-node-parent node))
                    ((equal (treesit-node-type parent) "pair"))
                    ((treesit-node-eq node (treesit-node-child-by-field-name parent "key"))))
          (setq node (treesit-node-child-by-field-name parent "value")))
        (unless node (user-error "No JSON value at point"))
        (let ((target node) (nodes (list node)))
          (while (treesit-node-parent node)
            (let* ((parent (treesit-node-parent node))
                   (type (treesit-node-type parent)))
              (cond
               ((equal type "pair")
                (let* ((key (json-parse-string
                             (treesit-node-text (treesit-node-child-by-field-name parent "key") t)))
                       (sibling (treesit-node-next-sibling parent t)))
                  ;; json.loads uses the LAST duplicate key.  Do not claim
                  ;; that a shadowed earlier value is reachable by data[key].
                  (while sibling
                    (when (and (equal (treesit-node-type sibling) "pair")
                               (equal key (json-parse-string
                                           (treesit-node-text (treesit-node-child-by-field-name sibling "key") t))))
                      (user-error "This value is shadowed by a later duplicate JSON key: %s" key))
                    (setq sibling (treesit-node-next-sibling sibling t)))
                  (push key parts)))
               ((equal type "array")
                (let ((index 0) (sibling (treesit-node-prev-sibling node t)))
                  (while sibling
                    (unless (equal (treesit-node-type sibling) "comment") (cl-incf index))
                    (setq sibling (treesit-node-prev-sibling sibling t)))
                  (push index parts))))
              (when (member type '("object" "array")) (push parent nodes))
              (setq node parent)))
          (list :parts parts :nodes nodes
                :expression (concat "data" (mapconcat
                                           (lambda (part) (format "[%s]" (if (integerp part) part (my/json-python-literal part))))
                                           parts ""))
                :type (treesit-node-type target)
                :value (buffer-substring-no-properties
                        (treesit-node-start target)
                        (min (treesit-node-end target) (+ (treesit-node-start target) 400))))))))
